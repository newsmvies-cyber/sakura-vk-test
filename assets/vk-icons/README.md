# Иконки приложения «Сакура»

Полноразмерная розовая заливка без светлой внешней рамки. Ветка и четыре крупных бутона занимают большую часть квадрата; рисунок основан на последнем присланном образце. PNG и Lottie используют общий силуэт.

- `sakura-icon-576.png` — универсальная иконка, 576 × 576 px.
- `sakura-icon-278.png` — иконка каталога и сниппетов, 278 × 278 px.
- `sakura-icon-150.png` — маленькая иконка, 150 × 150 px.
- `sakura-loader-96.json` — Lottie 96 × 96 px; бутоны раскрываются по очереди.
- `sakura-icon-master.svg` — редактируемый мастер-вектор.

Lottie-файл меньше ограничения 24 КБ.
