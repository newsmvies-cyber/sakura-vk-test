# Иконки Сакура

Основа — присланное владельцем изображение ролла. Оно не перерисовано; сохранены исходные цвета и пропорции. PNG подготовлены ресайзом исходного файла. Lottie использует тот же исходный рисунок и слегка покачивает его.

- sakura-icon-576.png — PNG 576 × 576.
- sakura-icon-278.png — PNG 278 × 278.
- sakura-icon-150.png — PNG 150 × 150.
- sakura-loader-96.json — Lottie 96 × 96; изображение встроено в JSON, знак покачивается примерно на ±6°.
