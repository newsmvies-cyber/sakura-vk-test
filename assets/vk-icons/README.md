# Иконки приложения «Сакура»

Комплект перерисован по присланному образцу: светлая подложка, вытянутая пудровая плашка, тонкая ветка и четыре бутона. Один мастер-вектор служит источником PNG и согласованной Lottie-анимации.

- `sakura-icon-576.png` — универсальная иконка, 576 × 576 px.
- `sakura-icon-278.png` — иконка каталога и сниппетов, 278 × 278 px.
- `sakura-icon-150.png` — маленькая иконка, 150 × 150 px.
- `sakura-loader-96.json` — Lottie 96 × 96 px; бутоны появляются по очереди.
- `sakura-icon-master.svg` — редактируемый мастер-вектор.

Перед загрузкой в VK проверьте превью анимации в кабинете. Файл Lottie должен оставаться меньше 24 КБ; комплект укладывается в этот лимит. Скриншот VK указывает, что иконку каталога/сниппета можно обновлять не чаще двух раз за две недели.
