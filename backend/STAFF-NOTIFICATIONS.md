# Уведомления сотруднику

Подготовлено локально. Отправка в VK по умолчанию выключена.

## Настройка после согласования публикации

- Использовать существующий ключ сообщества 242422490 с правом messages, если он уже настроен. Иначе создать ключ в Управление → Работа с API → Ключи доступа. Не передавать ключ в чат, Git или frontend.
- Сохранить ключ только в защищённой серверной настройке `VK_GROUP_TOKEN`.
- Установить `VK_STAFF_USER_IDS=229844423` и `VK_STAFF_NOTIFICATIONS_ENABLED=true`.
- Сотрудник разрешает сообщения от сообщества кнопкой в админке или открывает диалог с сообществом и разрешает сообщения. Проверить разрешение официальным messages.isMessagesFromGroupAllowed перед контрольной отправкой.
- Проверить соответствие активного пакета backend локальному коду до развёртывания: локальный index.js всё ещё содержит проверки юридических версий. Не заменять действующий пакет вслепую.
- Сохранить ID активной версии функции и конфигурацию без раскрытия секретов. Обновить существующую функцию, не меняя её авторизацию, YDB, Gateway или Timer. Таймаут функции должен учитывать запрос VK с ограничением 4 секунды.
- После публикации создать согласованную синтетическую заявку: она должна сначала сохраниться в YDB, затем прийти сообщением сотруднику. Проверить отказ обычному пользователю в admin API.

## Поведение и ограничения

Сообщение содержит только номер заявки и ссылку на приложение. Контакты клиента и адрес не отправляются. Получатели берутся исключительно из серверной настройки. Стабильный random_id уменьшает риск повторной отправки одного уведомления. Ошибка VK не отменяет сохранённую заявку. Постоянная очередь и гарантированная доставка не реализованы; после ошибки уведомление автоматически не повторяется. Для контроля проверять админку.

Звук включается вручную кнопкой в открытой админке; первый снимок старых заявок не озвучивается. Проверка новых заявок каждые 15 секунд только при видимой странице. Это до 240 чтений API в час активного просмотра админки. Браузер или система могут остановить звук при блокировке телефона. Уведомления VK зависят от настроек телефона и сообщества.

Откат: выключить VK_STAFF_NOTIFICATIONS_ENABLED, вернуть сохранённую версию функции; frontend вернуть предыдущим Git-коммитом. База и схема не меняются.

Дополнительно браузерная проверка на ширине 390 px с полностью имитированными API и AudioContext: ручное включение звука, новая заявка, отсутствие дублей, запрос разрешения VK. Реальная доставка VK и слышимость на телефоне пока не проверены.
